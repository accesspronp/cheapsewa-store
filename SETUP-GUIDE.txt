CHEAPSEWA STORE - SETUP GUIDE (v3)

1. GITHUB
   Delete the old files in your repo, then upload these FOUR items together (top level of the repo):
     package.json   netlify.toml   netlify (folder)   public (folder)
   Check on GitHub that public/index.html and netlify/functions/admin.mjs exist.

2. NETLIFY - set the admin password (THIS is what makes the admin work)
   Project configuration > Environment variables > Add variable
     Key:   ADMIN_PASSWORD
     Value: your admin password (at least 8 characters)
     Scopes: all / all contexts.   Tick "Contains secret values".
   Do NOT write the password in any file. The website files are public, so anyone could read it.

3. NETLIFY - redeploy
   Deploys > Trigger deploy > Deploy project. Wait for "Published".
   (Changing an environment variable only takes effect after a new deploy.)

4. Open https://YOUR-SITE.netlify.app/admin.html and sign in.
   If it fails, the red message under the box tells you exactly why:
     - "ADMIN_PASSWORD is not set"  -> step 2 + 3
     - "function not found (404)"   -> the netlify folder is missing from GitHub / wasn't deployed
     - "Wrong password"             -> retype it exactly

WHERE TO SEE CUSTOMER PAYMENT SCREENSHOTS
   Admin > Orders > on each order tap "View screenshot".
   Screenshots are stored privately on the server (Netlify Blobs), visible only to you in the admin,
   and auto-deleted after 60 days (change KEEP_DAYS in netlify/functions/cleanup.mjs).
   You can also see raw files in Netlify > Blobs (store name: screenshots).

ADMIN CAN
   Orders:    view screenshot, change stage, write a message to the customer, delete.
              Stages: Order received > Verifying payment > Payment approved >
                      Preparing subscription > Delivered (or Rejected)
   Products:  change every plan price, mark In stock / Out of stock (live on the site instantly).
   Customers: see name / email / phone, set a new password if they forget it.

CUSTOMERS
   /account.html  - create account (email + password) or sign in, then see live order tracking.
   Guests can track with Order ID + phone number.
   Passwords are stored as scrypt hashes: nobody (not even you) can read them.

PAYMENT LOGOS
   Desktop: eSewa, Khalti, Fonepay strip under the menu.
   Mobile:  Fonepay, eSewa, Khalti and Bank Transfer cards in "Pay your way".

IMAGES (v4)
   Hero banners:   public/assets/hero-store.webp and hero-payments.webp
   Product images: public/assets/products/<product id>.jpg  (1=ChatGPT 2=Claude 3=Perplexity 4=Gemini
                   5=Netflix 6=Spotify 7=YouTube 8=Canva 9=Adobe 10=Microsoft 365 11=Duolingo 12=Grammarly)
   To change one, replace that file with a new image (any size, ideal ratio 16:10, e.g. 800x500) keeping the same name.
   YouTube (7.jpg) is a placeholder because no YouTube image was supplied.

BANK LOGOS / MARQUEE (v5)
   Logos live in public/assets/banks/. The "We accept" strip scrolls right to left (pauses on hover).
   To add a bank: put its logo in that folder and add one <span class="bank-chip"><img src="assets/banks/NAME.webp" alt="Name"></span>
   inside the .bank-track in public/index.html (both places: top strip and mobile "Pay your way" card).
   Hero banner is 20% smaller; the green/black/purple pills are in public/index.html (class hero-pill).

ADMIN EDITING (v6)
   Admin > Products & prices, per product:
     - Change / crop image : pick a photo, drag + zoom inside the 16:10 frame, Save image (live instantly)
     - Product name and description
     - Plans: edit names and prices, remove with X, add "Quick add months" (1-24) or a custom plan
     - In stock / Out of stock
   Admin > Site text: edit the top bar, hero badge/paragraph, shop title/subtitle and help banner. Empty = original text.
   Images you upload are stored on the server (Netlify Blobs store "productimg"), not in GitHub.
   Mobile home page now shows only the scrolling "We accept" bank strip (no payment tiles).
